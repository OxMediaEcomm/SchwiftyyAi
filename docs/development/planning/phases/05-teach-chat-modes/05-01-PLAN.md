# Plan 05-01: Enhance teach.md — Skill Level Detection + Taught-Concept Tracking

## Goal

## Requirements Covered

- TEACH-04: Track what was taught via memory — do not re-explain covered concepts

## Tasks

### Task 1: Add Skill Level Detection section (TEACH-02)
On session start, before explaining anything:
- Check `.schwiftyy/memory.md` in the current project root (if it exists)
- Read the `skill_level` frontmatter field
- Adjust explanation depth:
  - `beginner`: maximum analogies, define every term, no assumed knowledge
  - `intermediate`: skip basics, explain patterns and WHY not HOW
  - `advanced`: minimal explanation, focus on tradeoffs and edge cases
- If no memory file or no skill_level: default to beginner depth, ask once: "Quick question — have you written code before, or is this your first time?"

### Task 2: Add Taught-Concept Tracking section (TEACH-04)
Before explaining any concept:
- Check `.schwiftyy/memory.md` "What Was Taught" section
- If the concept is already listed: acknowledge it briefly — "We covered this before — [one-line recap]. Want to go deeper or keep moving?"
- If not listed: teach it, then note it should be added to memory after the session
- Never silently re-teach something already covered — the user's time matters
