## Goal

Create the two-layer memory file structure, installer support for the memory directory, and first-run onboarding flow.

## Tasks

1. Create `schwiftyy/workflows/memory-init.md` — workflow Claude follows to initialize and read memory files
2. Update `bin/install.js` — create `~/.claude/schwiftyy/memory/` directory on install
3. Update `commands/schwiftyy/schwiftyy.md` — add first-run onboarding (MEM-10) + session resume prompt (MEM-08, MEM-09)

## File Structures Created

### Per-project: `.schwiftyy/memory.md`
```
---
project: <name>
last_session: <ISO date>
phase: <current phase>
skill_level: beginner | intermediate | advanced
---

## Next Action
- <single most important next step>

## Last Session
- <bullet: what happened, max 5 entries>

## Open Threads
- <unresolved questions / in-flight work>

## Decisions Made
- <locked architecture/design choices>

## What Was Taught
- <concepts explained — prevents re-teaching>
```

### Global: `~/.claude/schwiftyy/memory/global.md`
```
---
name: <user name>
skill_level: beginner | intermediate | advanced
preferred_stack: <stack>
first_seen: <ISO date>
last_seen: <ISO date>
---

## User Profile
- Name, skill level, preferred stack

## Cross-Project Patterns
- Only written when confirmed across 2+ projects

## Projects
- <project-name>: <one-line summary>
```

### First-run: `~/.claude/schwiftyy/memory/profile.md`
```
---
name: <name>
skill_level: <level>
preferred_stack: <stack>
onboarded: <ISO date>
---
```
