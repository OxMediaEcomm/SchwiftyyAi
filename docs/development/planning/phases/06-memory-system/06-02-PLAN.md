## Write Triggers (MEM-04)

Write to `.schwiftyy/memory.md` after:
- Architecture plan produced (build mode)
- First file written in a session (any mode)
- User makes a decision ("use Supabase for this")
- Concept explained (teach mode) → append to "What Was Taught"
- Session ends → update "Last Session" + "Next Action"

Never write on every message — milestone-gated only.

## Rotation Rule (MEM-05, MEM-06)

When `.schwiftyy/memory.md` hits 80 lines:
- Oldest entries from "Last Session" rotate to `.schwiftyy/memory-archive.md`
- Oldest entries from "What Was Taught" rotate to `.schwiftyy/memory-archive.md`
- "Next Action" and "Open Threads" are never rotated — sacred sections
- Archive format: append with `## Archived: <ISO date>` header
